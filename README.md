# 返済シミュレーション

ローンの返済額をシミュレーションする Web アプリです。ビルド不要の静的サイト（HTML / CSS / JavaScript）なので、`index.html` をブラウザで開くだけで動きます。

## できること

- **借入額**：1円〜100億円（10億円クラスもそのまま計算）
- **返済期間**：1ヶ月〜50年（年＋月で指定）
- **金利**：年0〜30%（小数点以下3桁まで）
- **返済方法**：元利均等返済 / 元金均等返済
- **変動金利**：「◯回目から◯%」の形で、期間の途中の金利変更をいくつでも追加可能
- **結果表示**
  - 毎月の返済額（初回）と、その元金・利息の内訳
  - 総支払額と、うち元金・うち利息
  - 金利期間ごとの内訳（金利変更がある場合）
  - 返済予定表（月別 / 年別切り替え、CSV ダウンロード）

## 計算方法

- 毎月の利息 = 残高 × 年利 ÷ 12（1円未満切り捨て）
- 元利均等返済の毎月返済額は年金現価の公式で算出（1円未満切り捨て）
- 金利が変わった回では、その時点の残高・残り回数・新金利で毎月返済額を再計算（元利均等）
- 元金均等返済は毎月の元金が一定で、金利変更時は利息部分だけが変わる
- 端数は最終回で精算

※ 実際の返済額は金融機関の端数処理や「5年ルール・125%ルール」の有無などで異なる場合があります。

## 開発

```bash
node --test test/loan.test.js
```

| `app.js` | 画面の入出力 |
| `test/loan.test.js` | 計算ロジックのテスト |
